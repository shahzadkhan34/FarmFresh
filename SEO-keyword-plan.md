## On-page SEO checklist applied
- Unique title tag (50–60 characters) with primary keyword first on every page
- Unique meta description (~150–160 characters) with keywords and a call to action
- One H1 per page containing the primary keyword; H2/H3 hierarchy for sections
- Primary keyword in the first 100 words
- Keyword-rich, hyphenated, lowercase URLs and image file names
- Descriptive alt text on every image; width/height set; lazy loading below the fold
- Internal links between all three pages + breadcrumbs; outbound links to authorities (USDA, European Commission)
- Robots meta, Open Graph and Twitter tags
- Schema.org structured data: Organization, Service, FAQPage, GroceryStore (LocalBusiness)
- Mobile-responsive layout, semantic HTML5, lang attribute, accessible form labels
- robots.txt
- Original content: the text from the original page was rewritten so it doesn't duplicate Wikipedia
